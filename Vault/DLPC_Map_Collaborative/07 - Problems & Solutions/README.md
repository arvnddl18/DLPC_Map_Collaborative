# 07 - Problems & Solutions

Store documented troubleshooting guides, root-cause analyses for tricky bugs, and documented failed approaches (to avoid repeating them) here.

## Successful Solution Template
```markdown
# Problem: [Issue Title]

## Symptom
[What broke]

## Root Cause
[Why it occurred]

## Solution
[Fix applied]

## Verification
[How it was tested and confirmed]

## Related
[[Architecture Note]]
```

## Failed Approach Template
```markdown
# Failed Approach: [Attempt Title]

## Attempt
[What was tried]

## Result
[Why it failed]

## Avoid When
[Context where this should not be tried]

## Alternative
[What worked instead]
```
